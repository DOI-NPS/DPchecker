# Tests for presence of a email in permissions/cui designation

This function

## Usage

``` r
test_cui_email(metadata = load_metadata(directory))
```

## Arguments

- metadata:

  The metadata object returned by `load_metadata`. If parameter is not
  provided, it defaults to calling `load_metadata` in the current
  project directory.

## Value

null (invisibly)

## Examples

``` r
if (FALSE) { # \dontrun{
test_cui_email()
} # }
```
